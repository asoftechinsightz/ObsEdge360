# Exit Criteria

Pilot may **exit successfully** when all apply:

1. Acceptance tests AT-01–AT-10 passed (or waived in writing).  
2. No open Critical defects attributable to OpsEdge360.  
3. Customer acknowledges Known Limitations (`docs/rc3/KNOWN_ISSUES.md`).  
4. Operations contacts and escalation path confirmed.  
5. Feedback form returned.  
6. Commercial next step recorded (expand / SOW / decline).

## Exit types

| Type | Meaning |
|------|---------|
| Convert | Move to paid / production SOW |
| Extend | Continue pilot with new end date |
| Pause | Freeze environment; revisit later |
| Close | Decommission pilot; retain lessons learned |
