# OpsEdge360 — End User Guide

## Getting Started

1. Open your organization's OpsEdge360 URL
2. Sign in with corporate SSO
3. Land on the **Executive Home** dashboard

## Navigation

| Menu | Purpose |
|------|---------|
| Home | Enterprise health overview |
| Digital Twin | Interactive topology map |
| CMDB | Asset inventory and relationships |
| Transactions | Business flow monitoring |
| Observability | Metrics, logs, traces |
| Security | Threats, fraud, anomalies |
| Compliance | Framework scores and evidence |
| Agents | AI activity and approvals |

## Executive Dashboard

View at-a-glance:
- **Availability** — overall service uptime
- **Revenue at Risk** — estimated hourly impact of outages
- **Compliance Score** — aggregate framework health
- **Security Posture** — active threats and severity
- **Sustainability** — energy and carbon metrics

Click any KPI to drill into details.

## Digital Twin

- **Pan/zoom** the topology graph
- **Filter layers**: IT, OT, Network, Security, Business
- **Click a node** to see health, owner, and dependencies
- **Impact analysis**: right-click → "Show blast radius"

## CMDB Explorer

- Search assets by name, type, or tag
- View relationships and change history
- See AI confidence score for auto-discovered items

## Business Transactions

- Select a transaction type (e.g. UPI Payment)
- View end-to-end flow with latency per step
- Drill into traces, logs, and correlated alerts

## Alerts

- **Acknowledge** alerts you're investigating
- **Escalate** to on-call team
- **View RCA** — AI-generated root cause hypothesis

## AI Agent Approvals

When an agent proposes a high-risk action:
1. Review explanation and evidence
2. Click **Approve** or **Reject**
3. Action executes automatically on approval

## Compliance (Auditors)

- Select framework (ISO 27001, PCI, etc.)
- Review control pass/fail status
- Export audit evidence package
