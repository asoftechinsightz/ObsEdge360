# ADR Template (EAB Mandatory Sections)

**Document ID:** OE360-ADR-TEMPLATE-001  
**Status:** FROZEN  
**Effective:** 2026-07-11  

Every ADR from ADR-009 onward (and all new ADRs) MUST include:

1. Business Context  
2. Problem Statement  
3. Decision  
4. Alternatives Considered  
5. Consequences  
6. Security Impact  
7. Performance Impact  
8. Scalability Impact  
9. Compliance Impact  
10. Rollback Strategy  
11. Future Considerations  
12. Decision Status — `Proposed` | `Accepted` | `Superseded` | `Deprecated`  

Header fields: ID/Title, Date, Deciders, Phase/Release, Depends on.
