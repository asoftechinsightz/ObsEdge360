# FAQ (Customer Knowledge Base)

**Q: What is OpsEdge360?**  
Enterprise digital operations intelligence — observability, CMDB/twin, ITSM, security posture, AI assist.

**Q: Is the platform feature-frozen?**  
Core platform is Engineering Freeze v1.0 except critical bugs, security, performance, and customer-requested enhancements.

**Q: How do pilots give feedback?**  
Via CS / pilot workshops; internal team logs into CVP Feedback (`/admin/cvp/feedback`).

**Q: Where are deployment docs?**  
See `docs/cvp/kb/DEPLOYMENT.md`, `docs/pilot/`, and `docs/commercial/`.
