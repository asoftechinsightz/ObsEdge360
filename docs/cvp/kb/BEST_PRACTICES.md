# Best Practices

1. Start with Executive Home + Ops Intelligence for demos.  
2. Enable Presentation mode for boardrooms (`Ctrl+Shift+P`).  
3. Define pilot success criteria before go-live.  
4. Log every enhancement request with a named customer.  
5. Prefer adoption metrics over feature count.  
6. Weekly health review using `docs/pilot/WEEKLY_HEALTH_REVIEW_TEMPLATE.md`.
