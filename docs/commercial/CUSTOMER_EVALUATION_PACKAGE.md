1. Commercial release tarball (or hosted pilot URL)  
2. [docs/pilot/CUSTOMER_ONBOARDING_GUIDE.md](../pilot/CUSTOMER_ONBOARDING_GUIDE.md)  
3. [docs/pilot/ACCEPTANCE_TEST_PLAN.md](../pilot/ACCEPTANCE_TEST_PLAN.md)  
4. Demo walkthrough — product `/demo` (Banking / Healthcare / Manufacturing / Retail / Government)  
5. Banking360 scenario — `/banking360`  
6. Security Center — MFA + session revoke — `/security`  
7. Feedback form — [docs/pilot/PILOT_FEEDBACK_FORM.md](../pilot/PILOT_FEEDBACK_FORM.md)  
8. Known issues — [KNOWN_ISSUES.md](./KNOWN_ISSUES.md)

- Full Chromium browser worker (simulated browser synthetics)  
- Full Helm microservice parity with Compose  
- Live 10k-user soak without Wave7 CERT staging  

## Conversion path

Evaluation → EPP pilot (`docs/pilot/`) → production SOW → testimonials / reference architecture.
