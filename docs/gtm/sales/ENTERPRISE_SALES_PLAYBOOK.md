# Enterprise Sales Playbook — OpsEdge360

## Ideal customer profile (ICP)

- Mid-to-large enterprise with complex IT operations (multi-domain, regulated or high-availability)  
- Pain: fragmented monitoring, weak executive risk view, slow incident RCA, audit pressure  
- Buyers: CIO / Head of Infra / SRE / CISO (influencer) / Procurement  
- Trigger events: outage, audit finding, tool consolidation, cloud + on-prem hybrid ops  

## Motion

1. **Discover** — Questionnaire + qualification (MEDDICC-lite).  
2. **Demo** — 15-minute executive path; optional technical deep dive.  
3. **Pilot** — EPP pack (`docs/pilot/`) with success criteria.  
4. **Procure** — Security / architecture package.  
5. **Produce** — Go-live checklist; CS owns 30/60/90.  
6. **Reference** — Case study template after 60–90 days healthy.  

## Stages & exit criteria

| Stage | Exit |
|-------|------|
| Prospect | ICP fit + discovery booked |
| Discover | Pain + economic buyer identified |
| Demo | Champion + next step (pilot or RFP) |
| Pilot | Signed pilot + kickoff |
| Propose | Commercial terms + procurement pack submitted |
| Closed won | MSA / order form |
| Adopt | Production + health score green |

## Talk track (one sentence)

OpsEdge360 is the enterprise digital operations intelligence platform that unifies observability, ITSM, compliance, and AI-assisted RCA so leaders see business risk—not just infrastructure noise.

## Collateral map

Pitch → Demo → Tech deep dive → Pricing → Procurement → Pilot onboarding.
