# Demo Script (10–15 minutes)

**Environment:** Pilot / demo plane · `/demo` reset before session  
**Audience:** Mixed exec + technical (adjust depth)

| Min | Screen | Say / do |
|-----|--------|----------|
| 0–1 | About / branding | “OpsEdge360 by AsoftechInsightz — enterprise digital operations intelligence.” |
| 1–3 | `/dashboard` | Single pane for risk, availability, business impact — not another raw metrics wall. |
| 3–6 | `/demo` industry tour | Pick Banking (or their industry). Walk 2–3 steps; open destination screens. |
| 6–8 | `/banking360` or synthetics | Regulated controls / payment SLOs **or** synthetic probes against critical journeys. |
| 8–10 | `/itsm` | Incident language executives recognize — severity, assignment, SLA. |
| 10–12 | `/copilot` | Ask for RCA summary / executive briefing — assist operators, don’t replace process. |
| 12–14 | `/security` | MFA, sessions, login history — procurement-ready posture. |
| 14–15 | Close | Propose pilot success criteria + next workshop. |

## Rules

- Reset demo between customers.  
- Disclose known limitations if asked (Helm subset, browser synthetics, soak evidence).  
- Never enable lab MFA codes on customer-facing systems.
