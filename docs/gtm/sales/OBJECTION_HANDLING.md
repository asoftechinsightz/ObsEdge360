# Objection Handling Guide

| Objection | Response |
|-----------|----------|
| “Too many tools already.” | Consolidation story: one ops intelligence plane; start with pilot scope, not rip-replace. |
| “Prove security.” | Hand procurement pack: MFA, encrypted secrets, session revoke, SBOM, RC3 assessment; offer review workshop. |
| “Need Kubernetes everything.” | Helm for gateway/web today; full mesh Compose-first—documented. Roadmap via customer demand (v1.1), not vapor. |
| “AI is hype.” | Copilot assists RCA/briefings; humans keep control. Show live prompt, not slideware. |
| “Show 10k users.” | Share Wave7 CERT path + modeled guidance; offer staging soak as SOW line item—don’t overclaim. |
| “Browser synthetics?” | Honest: simulated journeys now; Chromium worker is feedback-driven enhancement. |
| “Price?” | Value via ROI worksheet; pilot credit to Year-1; avoid discounting without champion. |
| “Build vs buy.” | Show time-to-pilot vs glue cost; freeze policy means we invest in customer success not endless features. |
| “When is SecureEdge360?” | OpsEdge360 is flagship until pilots/production/references exist—by design. |

## Never

- Promise unreleased product families as dependencies.  
- Hide known limitations.  
- Offer unlimited unpaid POCs.
