# Business Milestones (measure these — not engineering waves)

| # | Milestone | Definition of done | Status |
|---|-----------|--------------------|--------|
| M1 | First enterprise pilot signed | Signed pilot SOW / MSA + kickoff date | ☐ |
| M2 | First successful production deployment | Customer prod (or prod-like) live ≥30 days, health green | ☐ |
| M3 | First customer reference | Written permission to name account in sales | ☐ |
| M4 | First published case study | Approved one-pager live in marketing kit | ☐ |
| M5 | First ARR milestone | Define target (e.g. first ₹/USD ARR booking) and hit it | ☐ |
| M6 | First implementation partner | Signed partner agreement + trained lead | ☐ |
| M7 | First channel partner | Reseller agreement + first influenced opportunity | ☐ |
| M8 | Analyst briefing (optional/future) | Gartner / equivalent intro briefing held | ☐ |

## Leading indicators (weekly)

- Qualified discovery calls  
- Demos completed with economic buyer present  
- Procurement questionnaires in flight  
- Pilot health scores  

## Lagging indicators (quarterly)

- Pilots → production conversion rate  
- Logo references  
- Partner-sourced pipeline  

**Do not** treat “another feature wave complete” as a business milestone.
