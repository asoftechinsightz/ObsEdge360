# Partner Program Guide

## Motions

| Type | Role | When to recruit |
|------|------|-----------------|
| Implementation | Deploy, integrate, train | After ≥1 healthy pilot |
| Reseller / channel | Originate & close with AE overlay | After ≥1 reference |
| Technology | Integrate complementary tools | Case-by-case |

## Principles

- OpsEdge360 remains flagship; partners must not sell vapor Edge-family products.  
- Partners use the same GTM kit and known-limitations disclosure.  
- Margin / deal registration: _define in legal price book before launch_.  

## Partner obligations

- Trained consultants (certification path)  
- Preserve security defaults (no lab MFA in customer prod)  
- Submit diagnostics on escalations  
- Quarterly pipeline review
