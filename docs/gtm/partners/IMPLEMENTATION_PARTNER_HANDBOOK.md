# Implementation Partner Handbook

## Scope of work (typical)

- Install Compose/Helm/air-gap  
- SSO + MFA hardening  
- Backup/DR configuration  
- Initial dashboards / synthetics  
- Operator training  
- Hypercare (2–4 weeks)

## Delivery kit

Commercial tarball + `docs/pilot` + `docs/gtm/procurement` + diagnostics/DR scripts.

## Quality bar

- Acceptance tests signed  
- Health score baseline  
- No critical open defects at handoff  
- Customer can generate diagnostics unaided  

## Out of scope (unless SOW)

- Custom product modules  
- Guaranteeing industry certifications  
- Running Wave7 full-scale soak without env funding
