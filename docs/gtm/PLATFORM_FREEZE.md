# Platform Freeze Policy

## Freeze

Core OpsEdge360 feature development is **frozen** except:

| Allowed | Examples |
|---------|----------|
| Critical bugs | Auth outage, data corruption, install blockers |
| Security updates | CVE patches, MFA/secret hardening follow-ups |
| Performance improvements | Latency, pool sizing, soak fixes from pilots |
| Customer-requested enhancements | Scoped items from signed pilots / SOWs |

## Do not build (until milestones met)

- SecureEdge360, CloudEdge360, AgentEdge360, QuantumShield360  
- LeadEdge360, RetailEdge360, and other brand-family products  
- Speculative industry packs without a paying/pilot sponsor  
- Large rewrites of stable modules  

## Redirect energy to

1. AsoftechInsightz brand  
2. Landing enterprise pilots  
3. Sales & marketing assets (this kit)  
4. Customer feedback loops  
5. v1.1 informed by real usage
