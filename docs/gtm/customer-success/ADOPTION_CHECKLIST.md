# Adoption Checklist

## Executives

- [ ] View executive dashboard monthly  
- [ ] Receive one Copilot / report briefing  

## Operators

- [ ] Triage incidents in ITSM views weekly  
- [ ] Use synthetics or alerts on critical journey  
- [ ] Know how to pull diagnostics bundle  

## Administrators

- [ ] MFA + SSO (if applicable) maintained  
- [ ] Backups verified  
- [ ] User/role hygiene monthly  

## Organization

- [ ] Runbook links in customer wiki  
- [ ] Named backups for CS contacts  
- [ ] Success metric reviewed in QBR
