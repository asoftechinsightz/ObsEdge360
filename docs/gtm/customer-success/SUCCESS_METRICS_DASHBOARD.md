# Success Metrics Dashboard (Definition)

Not a product screen—**CS operating dashboard** (spreadsheet/CRM/BI).

## Mandatory widgets

1. Health score by account  
2. Days since last sponsor contact  
3. Open S1/S2 count  
4. Adoption checklist % complete  
5. Pilot → production conversion pipeline  
6. Reference readiness flag  
7. ARR / expansion pipeline (finance feed)  

## Account card fields

- Edition / SHA / env count  
- Success criteria text  
- Next QBR date  
- Risk notes  

## Review cadence

- CS team: weekly standup on yellow/red accounts  
- Leadership: monthly milestone review (`../BUSINESS_MILESTONES.md`)
