# Customer Onboarding Plan

## Pre-kickoff (T−7 to T0)

- [ ] Pilot/production SOW signed; success criteria written  
- [ ] CS owner + customer sponsor named  
- [ ] Environment topology chosen  
- [ ] Security contacts exchanged  
- [ ] Kickoff deck + commercial/pilot docs shared  

## Kickoff (T0)

- [ ] Goals, scope, non-goals, known limitations  
- [ ] Access provisioning plan  
- [ ] Demo vs production boundary  
- [ ] Cadence: weekly health + Slack/email path  

## Technical enablement (T0–T14)

- [ ] Install from commercial/pilot package  
- [ ] Admin MFA + policy  
- [ ] Backup configured  
- [ ] Acceptance tests witnessed (`docs/pilot/ACCEPTANCE_TEST_PLAN.md`)  

## Adoption enablement

- [ ] Role-based training (admin / operator / exec viewer)  
- [ ] Adoption checklist started  
- [ ] First value demo to sponsor (Banking360 or their pack)  

## Hand-off to steady state

- [ ] 30/60/90 plan agreed  
- [ ] Health score baseline recorded  
- [ ] Escalation matrix filled with real names  

Companion: `docs/pilot/CUSTOMER_ONBOARDING_GUIDE.md`, `docs/commercial/ADMINISTRATOR_GUIDE.md`.
