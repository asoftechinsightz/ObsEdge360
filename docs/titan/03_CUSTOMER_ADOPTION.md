# 03 — Workstream 3: Customer Adoption

**Goal:** Time-to-first-value measured in days, not quarters.

## Capabilities

| Need | Existing asset |
|------|----------------|
| Guided onboarding | `docs/pilot/CUSTOMER_ONBOARDING_GUIDE.md`, CS 30/60/90 (`docs/gtm/customer-success/`) |
| Product walkthroughs | `/demo` Executive Demo Mode, Evaluation Tours |
| Contextual help | `/help`, inline empty states (Discovery/Twin/Topology) |
| In-app documentation | Help Center + `docs/cvp/kb/` |
| Admin setup wizard | Discovery ConnectorWizard; SSO settings; Security MFA enroll |
| Feature discovery | Command palette, grouped nav, Executive Demo |
| Success score dashboard | `/admin/cvp/success` pilot health scores |

## Adoption KPIs (per pilot)

| KPI | Target (example — set per SOW) |
|-----|--------------------------------|
| Time to first dashboard value | ≤ 14 days |
| Weekly active operator seats | Agreed minimum |
| Synthetic coverage on tier-1 journeys | ≥ 1 journey live |
| MFA enabled for admins | Required where policy says |
| Health score (CVP) | ≥ 70 sustained 30 days |

## Cadence

- Day 0–7: onboarding checklist  
- Day 30/60/90: success plan reviews  
- Continuous: empty-state CTAs → Discovery / CMDB / Synthetics
