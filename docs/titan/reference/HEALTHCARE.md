# Reference Architecture — Healthcare

## Business outcomes

- Availability of patient-facing / clinical-adjacent digital channels  
- Audit-ready incident narrative  
- Strict tenancy and SSO  

## Topology notes

- Prefer customer-controlled deployment  
- PHI/PII handling is **customer policy** — platform hosts where customer deploys  
- Start with non-PHI demo data in pilots  

## Integrations

Entra ID / SAML · OTel · ITSM · notification channels  

## Success metrics

Channel uptime · incident brief time · MFA · change correlation usage
