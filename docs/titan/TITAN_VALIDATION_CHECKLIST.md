# TITAN Validation Checklist

Use before declaring “ready to support paying customers at scale.”

## WS1 Production Operations
- [ ] Daily/weekly/monthly ops cadence assigned
- [ ] Backup verification executed & dated
- [ ] DR drill documented (tabletop minimum)
- [ ] Capacity baseline per pilot
- [ ] Release health checked at go-live

## WS2 Enterprise Support
- [ ] Diagnostics bundle runnable
- [ ] Escalation path published
- [ ] Feedback logged in CVP for each Sev issue
- [ ] Health report path known (`/reports` + CS dashboard)

## WS3 Adoption
- [ ] Onboarding guide followed
- [ ] Demo/walkthrough available
- [ ] Success score tracked in CVP
- [ ] Empty-state paths lead to Discovery/setup

## WS4 Analytics
- [ ] Privacy posture disclosed as needed
- [ ] Aggregated analytics reviewed weekly by CS/Product

## WS5 Scalability
- [ ] Sizing guide applied
- [ ] HA posture reviewed for production conversions

## WS6 Integrations
- [ ] Priority IdP working
- [ ] Notification channel verified
- [ ] Connector health green for in-scope sources

## WS7 Reference Architecture
- [ ] Industry blueprint shared with customer architects

## WS8 Evidence
- [ ] Evidence record completed per active pilot
- [ ] Dual-customer rule applied to any v1.1 candidate

## Governance
- [ ] Engineering Freeze still respected
- [ ] No Edge-family product started
- [ ] Six-month priorities reviewed with leadership
