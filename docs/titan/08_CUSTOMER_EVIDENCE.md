# 08 — Workstream 8: Customer Evidence

**Goal:** Every pilot produces case-study-ready evidence and feeds Version 1.1.

## Capture for every pilot

| Field | Why |
|-------|-----|
| Business problem | Story for buyers |
| Deployment time | Proof of time-to-value |
| User adoption | Seats, workflows used |
| Measured outcomes | MTTR, SLA, risk reduction, audit hours |
| Lessons learned | Product honesty |
| Enhancement requests | Feature Board intake |

## Template

Use [templates/PILOT_EVIDENCE_RECORD.md](./templates/PILOT_EVIDENCE_RECORD.md).  
Mirror summary fields in `/admin/cvp/pilots` (success criteria, issues, requests, health).

## Output chain

```
Pilot evidence → CVP Feedback/Feature Board → v1.1 backlog
              → Case study (docs/gtm/marketing/CASE_STUDY_TEMPLATE.md)
              → Sales references (business milestones)
```

## Rule

No evidence → no case study claim → no roadmap inflation.
