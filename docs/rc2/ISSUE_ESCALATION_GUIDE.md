# Issue Escalation Guide

| Severity | Example | Response target | Escalate to |
|----------|---------|-----------------|-------------|
| Critical | Auth down, data exposure | 15 min | On-call + Eng lead |
| High | MFA broken, pilot blocked | 1 hour | Pilot engineer |
| Medium | UI defect, non-blocking API | 1 business day | Support |
| Low | Cosmetic / docs | Next release | Backlog |

Include: tenant, SHA, request ID, screenshots, reproduction steps.  
Security incidents: follow Security Assessment + audit export.
