# SLA Guide — Pilot

Pilot SLA (default, adjustable per contract):

| Metric | Target |
|--------|--------|
| Platform availability (pilot window) | 99.5% |
| Severity 1 response | 15 minutes |
| Severity 2 response | 1 hour |
| Severity 3 response | 1 business day |
| Scheduled maintenance notice | 48 hours |

Production SLAs are commercial-contract specific and supersede pilot defaults.
